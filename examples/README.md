Fertige Fusion-Dateien zum Anschauen, nicht zum blinden Nachdrucken unter Druck.

| Datei | Was |
|-------|-----|
| `CO2-Gewindeschutzkappe.f3d` | Schutzkappe auf DIN-477-Gewinde. Nur Staubschutz, kein Druckbehälter. |

Öffnen in Fusion: Datei → Öffnen → diese `.f3d`. Das Gewinde kommt aus `threads/02_DIN477_CO2.xml`.
